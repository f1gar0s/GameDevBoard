# 🎮 GameDev Board

**Онлайн-доска в стиле Miro для разработчиков игр.** Бесконечный холст со стикерами, фигурами, фреймами и связями плюс инструменты, которых нет в обычных досках: диалоги можно сразу проиграть, уровни — пройти, а баланс — посчитать.

Сайт статический (HTML + JS, без сборки и без сервера), поэтому бесплатно хостится на **GitHub Pages**.

---

## 🗂 Иерархия: разделы и фреймы

Доска делится на **фреймы** — отдельные страницы. На холсте всегда виден только открытый фрейм, поэтому даже очень большой проект не тормозит.

- Панель **«Иерархия»** слева (кнопка 🗂 или клавиша **B**): разделы → подразделы любой глубины → фреймы, как Hierarchy в Unity. Ширину панели можно менять, потянув за правый край.
- **📁+ / 📄+** — новый раздел / фрейм (в выбранном разделе или на верхнем уровне). Двойной клик или F2 — переименовать, перетаскивание — переложить в другой раздел или поменять порядок, ПКМ или ⋯ — меню (подраздел, фрейм, ссылка, удалить).
- Сверху показан путь к открытому фрейму; ‹ › или **Alt+↑/↓** — предыдущий/следующий фрейм.
- **Ссылки:** выделите слова в тексте → «🔗 Ссылка» (Ctrl+K) → выберите фрейм или объект в дереве; слова, совпадающие с названием фрейма, становятся ссылками сами (подробнее — в разделе «Объекты»).
- Выделенные элементы переносятся на другой фрейм через список **📄 →** на панели над выделением. Старая рамка на холсте теперь называется **областью** (клавиша F, канбан-колонки работают как раньше); кнопка «📄 В отдельный фрейм» превращает область вместе с содержимым в новый фрейм — так удобно разнести старую большую доску.
- Обзор, поиск и проверки работают по всей доске: клик по найденному элементу откроет нужный фрейм. GDD собирается по иерархии.
- В совместной работе иерархия синхронизируется, у каждого участника открыт свой фрейм, а цветные точки в дереве показывают, кто на каком фрейме.

## 🖥 Свой сервер (рекомендуется для команды)

Публичные серверы синхронизации бесплатны, но ничего не гарантируют и в России работают нестабильно. На своём VPS (подойдёт самый дешёвый, например VDSina 1 ГБ) доска открывается и синхронизируется и с VPN, и без него.

1. Купите VPS с **Ubuntu 24.04** в Москве или Петербурге. Желательно купить домен (например, `.ru`) и в настройках DNS направить его A-запись на IP сервера. Можно без домена — тогда будет бесплатный адрес вида `1-2-3-4.sslip.io`.
2. Подключитесь к серверу по SSH (`ssh root@IP`, пароль пришлёт хостер) и выполните, подставив свои данные:

   ```bash
   apt-get update && apt-get install -y git
   git clone https://github.com/f1gar0s/GameDevBoard.git /var/www/gdboard
   bash /var/www/gdboard/server/setup.sh https://github.com/f1gar0s/GameDevBoard.git board.example.ru you@mail.ru
   ```

   Без домена — просто не указывайте два последних параметра.
3. Откройте `https://ваш-домен`. Синхронизация сама пойдёт через ваш сервер (в окне «Совместно» будет написано «через ваш сервер»).

Скрипт ставит nginx (сайт и HTTPS через Let's Encrypt), Mosquitto (хранение и синхронизация досок, доступен только изнутри сервера), скачивает шрифты на сервер, каждый день делает резервную копию досок в `/var/backups/gdboard` (14 дней).

**Обновление** после `git push`: зайти на сервер и выполнить `gdboard-update`.

**Перенос досок** со старого адреса (GitHub Pages): у нового сайта своё хранилище в браузере, поэтому откройте доску на старом адресе → «Экспорт» → «Файл доски», затем на новом → «Импорт» и снова откройте совместный доступ.

## 👥 Совместный доступ (работает на GitHub Pages)

1. Откройте доску → **👥 Совместно** → **Открыть совместный доступ**.
2. Отправьте ссылку команде. По ней доска открывается у всех, правки и курсоры видны в реальном времени.
3. Доска хранится в «комнате» на сервере синхронизации, поэтому ссылку можно открыть в любой момент, даже если создатель офлайн.
4. Картинки синхронизируются у всех участников. Большие фото при вставке уменьшаются до 1600 px и пережимаются в WebP. Картинку, вставленную без связи, приложение досылает после переподключения, а если у кого-то её не хватает, запрашивает у других участников.

Как это устроено: GitHub Pages отдаёт только статические файлы, поэтому браузеры обмениваются изменениями через публичный MQTT-брокер по защищённому `wss://`. Всё содержимое (доска, картинки, курсоры) шифруется AES-256-GCM ключом, который есть только в ссылке (после `#`, на сервер он не уходит). Брокер хранит лишь шифротекст.

- **Без VPN.** Доска подключается сразу к четырём публичным серверам (Eclipse на порту 443, EMQX, HiveMQ, Mosquitto) и отправляет правки во все доступные. Если какой-то сервер заблокирован у провайдера, работают остальные. В окне «Совместно» видно, какие серверы доступны и с какой задержкой; сервер, который был недоступен, после подключения автоматически получает недостающие данные. Можно указать и свой брокер.
- **Мгновенная синхронизация.** Между участниками устанавливается прямое соединение браузер↔браузер (WebRTC DataChannel); серверы нужны только для «знакомства» и для тех, кто откроет ссылку позже. Правки и курсоры идут без задержек и продолжают ходить, даже если все серверы временно недоступны. Если прямое соединение невозможно (строгий NAT), всё работает через серверы. Дубли сообщений, пришедших разными путями, отбрасываются.

## 🧩 Объекты

Всё на доске — **объекты**: стикер, текст, фигура, область, реплика диалога, картинка, видео и карточки-объекты (Карточка, Баг, Задача, Персонаж, Предмет, Квест, Таблица, Список, Генератор карт 2D, Уровень, Кривая баланса, Таблица лута, Холст со слоями, Спрайт-анимация, Палитра).

- У карточки фиксированный набор полей. **⚙ в шапке** открывает настройки полей сразу для всей карточки: к какому списку привязан выпадающий список, подписи, стили, размеры.
- **Выпадающий список** берёт варианты (текст + цвет) из объекта **«Список»**. Один список обслуживает сколько угодно объектов: переименовали вариант — обновилось везде. Таблица лута выбирает предметы из объектов «Предмет» на доске.
- Картинка, брошенная на карточку, заполняет её пустое поле «Картинка» или «Спрайт», а если такого нет — ложится рядом отдельным объектом.

### Гиперссылки в тексте
- **Своя ссылка:** начните править текст (двойной клик по стикеру/тексту, клик по полю текста в выделенной карточке), выделите нужные слова — появится кнопка **«🔗 Ссылка»** (или нажмите **Ctrl+K**). В окне выбора — дерево: разделы → фреймы → объекты внутри каждого фрейма, с поиском. Ссылка ведёт на фрейм или на конкретный объект; если объект на другом фрейме, сначала откроется этот фрейм. Ссылку можно изменить или убрать той же кнопкой.
- **Автоссылки:** слово (или фраза), совпадающее с названием фрейма без учёта регистра, само становится ссылкой — написали «ЭЛЬФЫ», и это ссылка на фрейм «Эльфы». Переименовали фрейм — автоссылки обновились. Автоссылки подчёркнуты пунктиром, свои — сплошной линией.
- Во время правки ссылки — обычный текст (Ctrl+клик всё равно переходит).

### Раскладка внутри области
Область (рамка, клавиша F) может сама раскладывать объекты, как контейнеры в Godot. На панели над выделенной областью: **✥ Свободно**, **⇄ Строка** (HBoxContainer), **⇅ Столбец** (VBoxContainer), **▦ Сетка** (GridContainer, число столбцов задаётся рядом). Порядок задаётся тем, куда вы бросили объект; область сама подстраивает размер, вытащенный объект перестаёт участвовать в раскладке.

### Для разработчиков: модули полей
Поля карточек описаны модулями в папке `components/` (`text.js`, `dropdown.js`, `list.js`, `table.js`, `tilemap.js`, `loottable.js`…) и перечислены в `components/manifest.js`. Это внутреннее устройство: в интерфейсе поля нельзя добавлять и удалять, набор полей каждого объекта задан в `js/tools.js`. Модуль описывает `render(ctx)`, необязательные `settings(ctx)` (показываются по ⚙ карточки), `deps`, `watch`, `text`, `exportMd`, `exportJson`; через `extends` можно взять логику другого модуля (пример — `header.js`).

## 🚀 Публикация на GitHub Pages

### Вариант 1 — автоматически (Windows)
1. Установите [Git](https://git-scm.com/download/win) и, желательно, [GitHub CLI](https://cli.github.com/).
2. Дважды щёлкните **`publish.bat`** в этой папке.
3. Скрипт создаст репозиторий `GameDevelopmentBoard`, отправит код и включит Pages. Сайт будет по адресу
   `https://<ваш-логин>.github.io/GameDevelopmentBoard/`

### Вариант 2 — вручную
```bash
git init -b main
git add -A
git commit -m "GameDev Board"
git remote add origin https://github.com/<логин>/GameDevelopmentBoard.git
git push -u origin main
```
Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
Через минуту сайт появится по адресу `https://<логин>.github.io/GameDevelopmentBoard/` и будет обновляться при каждом `git push`.

## 💻 Локальный запуск
Из-за ES-модулей файл нельзя открыть двойным кликом, нужен любой локальный сервер:
```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## 🧩 Структура
```
index.html          — разметка
css/style.css       — стили
js/app.js           — главная страница, панели, маршруты
js/canvas.js        — холст: зум, выделение, перетаскивание, связи, инструменты
js/widgets.js       — базовые элементы (стикер, текст, фигура, фрейм, реплика) + карточка
js/card.js          — карточка-объект: поля и их настройки (⚙ в шапке)
js/richtext.js      — текст с гиперссылками и автоссылками на фреймы
js/picker.js        — окно выбора цели ссылки (дерево фреймов с объектами)
js/hierarchy.js     — панель иерархии: разделы и фреймы
js/registry.js      — загрузка модулей полей из папки components/, наследование extends
js/tools.js         — инструменты (пресеты карточек), списки по умолчанию, миграция старых досок
js/lib.js           — общая логика для полей (формулы, тайлы, анимация)
components/         — модули полей карточек, по файлу на каждый, + manifest.js
js/play.js          — плейтест диалогов и уровней
js/templates.js     — шаблоны досок
js/export.js        — GDD, JSON для движка, файлы, ссылки
js/collab.js        — совместный доступ: комнаты, шифрование, синхронизация
js/mqtt.js          — минимальный MQTT-клиент поверх WebSocket (без внешних библиотек)
js/store.js         — состояние, история, IndexedDB
```

## Ограничения
- Доски хранятся локально в браузере. Чтобы перенести доску на другое устройство, используйте файл доски или ссылку-снимок.
- Совместный доступ идёт через бесплатные публичные MQTT-брокеры (сразу через все доступные). У них нет гарантий хранения: доска хранится сразу на нескольких, а для надёжности можно указать свой (например, бесплатный HiveMQ Cloud). Локальная копия доски всегда остаётся в браузере.
- Содержимое шифруется, но идентификатор комнаты виден брокеру. Ссылка = ключ: не публикуйте её открыто.
