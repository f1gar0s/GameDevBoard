# 🎮 GameDev Board

**Онлайн-доска в стиле Miro для разработчиков игр.** Бесконечный холст со стикерами, фигурами, фреймами и связями плюс инструменты, которых нет в обычных досках: диалоги можно сразу проиграть, уровни — пройти, а баланс — посчитать.

Сайт статический (HTML + JS, без сборки и без сервера), поэтому бесплатно хостится на **GitHub Pages**.

---

## 🧩 Карточки и компоненты (как в Unity)

Каждый элемент доски, кроме стикеров, фигур, фреймов и реплик, — это **карточка**, собранная из **компонентов**, как GameObject в Unity.

- **Инструмент** — готовая карточка с набором компонентов: Пустая карточка, Баг, Задача, Персонаж, Предмет, Квест, Таблица, Список, Генератор карт 2D, Уровень (тайлы), Кривая баланса, Таблица лута, Холст со слоями, Спрайт-анимация, Палитра. Реплика диалога остаётся отдельным элементом со стрелками-ответами.
- На любую карточку можно добавить ещё компоненты кнопкой **«+ Компонент»**. Компоненты идут сверху вниз; их можно перетащить за **⠿**, сдвинуть **↑ ↓**, настроить через **⚙** и удалить **×**.
- **Выпадающий список** берёт варианты (текст + цвет) из отдельной карточки со «Списком вариантов». Один список может обслуживать сколько угодно карточек: переименовали вариант — обновились все.
- **Кнопка-ссылка** переносит к выбранному фрейму; шестерёнка рядом с кнопкой открывает её настройку.

### Как написать свой компонент
1. Создайте файл в папке `components/`, например `components/hp-bar.js`.
2. Допишите его имя в `components/manifest.js` (родитель должен стоять выше наследника).
3. Обновите страницу — компонент появится в меню «+ Компонент».

```js
// components/hp-bar.js — полоска здоровья, наследует «Число»
export default {
  type: 'hp-bar',
  extends: 'number',              // берём логику number.js
  name: 'Полоска HP',
  icon: '❤',
  group: 'Геймдизайн',
  defaults: () => ({ label: 'HP', value: 80, max: 100 }),
  render(ctx) {
    const el = ctx.base();        // оригинальная отрисовка «Числа»
    const pct = Math.min(100, (ctx.data.value / (ctx.data.max || 100)) * 100);
    el.append(ctx.h('div', { class: 'bar', style: { width: '100%' } },
      ctx.h('i', { style: { width: pct + '%', background: '#ef4444' } })));
    return el;                    // + наш код поверх
  },
};
```

Что доступно в `ctx`: `data` (данные компонента), `field(key, opts)` (поле ввода, связанное с данными), `live / set / change` (сохранить без перерисовки / с перерисовкой / с точкой отмены), `base()` (логика родителя), `h` (создание элементов), `lib` (формулы, тайлы), `dropdown`, `lists`, `ensureList`, `focusItem`, `frames`, `asset`, `addAsset`, `pickImage`, `toast`, `download`, `toggleSettings`. Необязательные поля описания: `settings(ctx)` (панель ⚙), `deps(data)` (от каких карточек зависит), `text`, `exportMd`, `exportJson`, `openOnAdd`.

Старые доски с персонажами, задачами и таблицами лута при открытии автоматически превращаются в карточки с компонентами.

## ✨ Фишки для геймдева

| | Фишка | Что делает |
|---|---|---|
| 💬 | **Плейтест диалогов** | Реплики связываются стрелками, подпись стрелки — вариант ответа игрока. Кнопка **▶ Играть** запускает диалог в стиле визуальной новеллы, и текущая реплика подсвечивается на доске. |
| 🗺 | **Уровни и карты** | Статичная тайловая карта (стены, лава, враги, монеты, ключи, двери, старт, выход) с экспортом PNG/TXT и **генератор 2D-карт** в средневековом или современном стиле по зерну. |
| 📈 | **Кривые баланса** | Пишете формулы вида `XP: 100 * lvl^1.5` и сразу видите график. Можно сравнивать несколько кривых, например доход и цены. |
| 🎲 | **Лут-таблицы** | Веса, редкость, шансы в %, бросок и симуляция 1000 бросков (фактическая частота рядом с ожидаемой). |
| 🧙 | **Карточки сущностей** | Персонажи (статы с полосками), предметы (редкость, цена), квесты (цели-чекбоксы, награда). |
| 🏃 | **Канбан** | Фрейм можно сделать колонкой: брошенная в него карточка получает вариант с названием фрейма в своём выпадающем списке (например «В работе»). |
| 📊 | **Обзор проекта** | Прогресс спринта, story points, открытые баги, нагрузка по людям, список сущностей, поиск. |
| ⚠ | **Проверка** | Находит пустые и несвязанные реплики, уровни без старта или выхода, дверь без ключа, ошибки в формулах, повторяющиеся имена. |
| 👾 | **Спрайт-анимации** | Загрузите спрайт-лист, укажите колонки, ряды и FPS — анимация проигрывается на доске. |
| 🎨 | **Палитры** | Цвета арт-направления, HEX копируется по клику. |
| 🎮 | **Экспорт в движок** | JSON с персонажами, предметами, квестами, графом диалогов, уровнями, таблицами значений кривых и лутом — для Unity, Godot или Unreal. |
| 📘 | **GDD в Markdown** | Из фреймов и карточек собирается документ дизайна игры. |
| 👥 | **Совместная работа** | Сессия в реальном времени через WebRTC (PeerJS): курсоры, присутствие, синхронные правки. Свой сервер не нужен. |
| 🔗 | **Ссылка-снимок** | Вся доска сжимается прямо в URL, так что поделиться можно без сервера. |

## 🚀 Публикация на GitHub Pages

### Вариант 1 — автоматически (Windows)
1. Установите [Git](https://git-scm.com/download/win) и, желательно, [GitHub CLI](https://cli.github.com/).
2. Дважды щёлкните **`publish.bat`** в этой папке.
3. Скрипт создаст репозиторий `GameDevelopmentBoard`, отправит код и включит Pages. Сайт будет по адресу
   `https://<ваш-логин>.github.io/GameDevelopmentBoard/`

### Вариант 2 — вручную
```bash
git init -b main
git add -A
git commit -m "GameDev Board"
git remote add origin https://github.com/<логин>/GameDevelopmentBoard.git
git push -u origin main
```
Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
Через минуту сайт появится по адресу `https://<логин>.github.io/GameDevelopmentBoard/` и будет обновляться при каждом `git push`.

## 💻 Локальный запуск
Из-за ES-модулей файл нельзя открыть двойным кликом, нужен любой локальный сервер:
```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## 🧩 Структура
```
index.html          — разметка
css/style.css       — стили
js/app.js           — главная страница, панели, маршруты
js/canvas.js        — холст: зум, выделение, перетаскивание, связи, инструменты
js/widgets.js       — базовые элементы (стикер, текст, фигура, фрейм, реплика) + карточка
js/card.js          — карточка-контейнер: компоненты, ⚙, перестановка, меню добавления
js/registry.js      — загрузка компонентов из папки components/, наследование extends
js/tools.js         — инструменты (пресеты карточек), списки по умолчанию, миграция старых досок
js/lib.js           — общая логика для компонентов (формулы, тайлы, анимация)
components/         — компоненты, по файлу на каждый, + manifest.js
js/play.js          — плейтест диалогов и уровней
js/templates.js     — шаблоны досок
js/export.js        — GDD, JSON для движка, файлы, ссылки
js/collab.js        — совместная работа (WebRTC / PeerJS)
js/store.js         — состояние, история, IndexedDB
```

## Ограничения
- Доски хранятся локально в браузере. Чтобы перенести доску на другое устройство, используйте файл доски или ссылку-снимок.
- Совместная работа устанавливает прямое соединение между браузерами. Сессия живёт, пока открыта вкладка хоста. В строгих корпоративных сетях соединение может не установиться.
